================================================================================
HOW TO GET CREDENTIALS
================================================================================

MongoDB URI:
  1. Go to https://www.mongodb.com/cloud/atlas
  2. Create free account
  3. Create cluster
  4. Create database user
  5. Copy connection string
  6. Replace username and password

OpenRouter API Key:
  1. Go to https://openrouter.ai
  2. Sign up for free account
  3. Go to API Keys
  4. Generate new key
  5. Copy and save securely

================================================================================
API ENDPOINTS
================================================================================

POST /api/generate
  Creates new project with AI
  Input: { projectName, description, template, features }
  Output: { project: { id, name, files } }

GET /api/projects
  List all projects
  Output: { projects: Project[] }

GET /api/projects/[id]
  Get single project
  Output: { project: Project }

PUT /api/projects/[id]
  Update project
  Input: Project data
  Output: { project: Project }

DELETE /api/projects/[id]
  Delete project
  Output: { success: true }

COMMON ISSUES & FIXES
================================================================================

Issue: "OPENROUTER_API_KEY is not set"
Fix: Add to .env.local: OPENROUTER_API_KEY=sk_live_xxxxx

Issue: "Cannot connect to MongoDB"
Fix: 
  • Verify MongoDB URI is correct
  • Check MongoDB Atlas IP whitelist
  • Ensure database user exists
  • Test connection string in MongoDB Atlas

Issue: "Port 3000 already in use"
Fix: npm run dev -- -p 3001  (use different port)

Issue: "Generation is slow"
Fix: First generation takes 30-60 seconds. This is normal.

See SETUP.md for more troubleshooting.
